# ADR 0003: MVP 权限模型

## 状态

建议采用。

## 背景

MVP 目标是降低使用门槛。强制注册会增加摩擦，但完全无权限会导致组织者和参与者互相误改数据。

## 决策

MVP 不做账号系统，使用链接密钥模型：

- 公共分享链接允许查看日程和新增参与者提交。
- 组织者管理链接包含一次性生成的管理密钥。
- 参与者编辑链接包含一次性生成的编辑密钥。
- 服务端只保存密钥哈希。
- 管理密钥可以锁定日程和后续执行管理操作。
- 编辑密钥只能修改对应参与者的提交。

## 结果

优点：

- 创建和填写流程短。
- 不需要登录系统即可验证核心需求。
- 未来可以平滑升级到账号系统。

代价：

- 用户丢失管理链接后无法自助找回。
- 链接被转发时，持有人拥有对应权限。

## 后续检查

当出现以下需求时重新评估：

- 用户要求长期保存历史日程。
- 组织者需要管理多个固定群组。
- 需要付费、团队空间或日历同步。
