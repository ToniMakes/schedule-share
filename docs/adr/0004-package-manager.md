# ADR 0004: 包管理器和工作区

## 状态

建议采用。

## 背景

项目需要同时维护 Web 应用、核心业务包、数据库包和未来小程序入口。单仓库可以减少跨端复用成本，但需要明确工作区和依赖边界。

## 决策

使用 pnpm workspace 管理 monorepo：

- `apps/*` 放具体应用。
- `packages/*` 放可复用包。
- 根目录提供统一的 `build`、`dev`、`lint`、`test`、`typecheck` 命令。

## 结果

优点：

- 依赖安装和锁定更可控。
- 适合多包项目。
- 后续可以让 Web 和小程序共享 `packages/core`。

代价：

- 需要团队成员安装 pnpm。
- 一些第三方工具可能需要额外配置 workspace 路径。

## 后续检查

如果未来小程序工具链与 pnpm workspace 兼容性差，需要单独写 ADR 评估调整方案。
