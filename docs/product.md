# 产品说明

## 产品定位

这是一个面向跨时区多人协调的日程共享工具。用户可以创建一个日程房间，邀请其他人填写可用时间，并快速找出所有人或大多数人都方便的时间段。

第一阶段优先服务海外用户和少量国内用户，通过移动优先的网页版验证需求。微信小程序作为第二阶段入口，复用同一套后端 API 和核心业务逻辑。

## 目标用户

- 经常组织多人会议、聚会、课程、社群活动的人。
- 海外华人、跨国家庭、留学生、远程团队和兴趣社群。
- 不想注册复杂账号，只想快速收集时间的人。

## 核心场景

1. 组织者创建日程房间，设置日期范围、每天可选时间段和时间粒度。
2. 系统生成分享链接。
3. 参与者通过链接填写姓名和可用时间。
4. 系统自动计算并展示共同空闲时间与多数人空闲时间。
5. 组织者复制候选时间，或锁定最终时间。

## MVP 范围

MVP 必须包含：

- 创建日程房间。
- 设置日期范围。
- 设置每天可选时间窗口。
- 设置时间粒度：15、30 或 60 分钟。
- 分享公开填写链接。
- 参与者使用昵称填写可用时间。
- 参与者可使用编辑密钥修改自己的提交。
- 展示所有人都有空的时间段。
- 展示按可用人数排序的候选时间段。
- 移动端可用。

MVP 暂不包含：

- 微信小程序。
- 支付和会员。
- 复杂团队管理。
- Google Calendar、Outlook、Apple Calendar 深度同步。
- 微信登录、邮箱登录或手机号登录。
- 自动短信、邮件或微信提醒。
- 实时协同编辑。
- 活动报名和票务。

## 成功标准

第一版上线后，优先观察这些指标：

- 组织者能否在 1 分钟内创建并分享日程。
- 参与者能否在 30 秒内完成填写。
- 单个日程是否能支持 5 到 20 人稳定使用。
- 创建者是否会创建第二个日程。
- 用户是否愿意把链接分享到微信、WhatsApp、Telegram 或邮件。

## 产品原则

- 参与者不需要注册。
- 创建和填写流程必须短。
- 结果页必须一眼看出最佳时间。
- 核心填写流程不放干扰性广告。
- 支持跨时区是基础能力，不是高级功能。
- 数据和权限规则宁可简单，也要明确。

## 后续方向

在 MVP 被真实使用后，再根据数据选择扩展方向：

- 高频组织者功能：模板、群组、导出、提醒、隐藏广告。
- 机构版：品牌页、多人管理、批量活动。
- 微信小程序：微信群分享、微信生态内填写体验。
- 日历集成：导入忙闲状态、导出最终时间。
