# 关于日程表共享

更新日期：2026-08-02

## 定位

日程表共享是一个轻量的跨时区多人日程共享工具。组织者创建日程并分享链接，参与者填写自己的可用时间或候选时间偏好后，系统自动汇总全员可用时间和覆盖人数最多的较优时间段。

第一阶段服务一次性或短期排期场景，不要求注册账号，不要求安装应用。

## 适合场景

- 海外同学约小组作业、社团活动或周末聚会。
- 跨城市朋友协调聚餐、旅行讨论或线上语音时间。
- 小团队安排一次性会议、面试、志愿者排班或临时值班。
- 老师、助教、社群组织者收集一组人的可用时间。

## 当前能力

- 跨时区日程创建和匿名链接分享。
- 手动时间格填写，支持点按和涂选。
- 候选时间投票，支持方便、也许、不方便和偏好顺位。
- 文本、CSV、ICS 和受闸门保护的图片导入预览路径。
- 公开结果页、组织者管理页、CSV / ICS 导出和最终时间确认。
- 默认关闭的常驻广告位框架和 `/ads.txt` 路由。

## 数据边界

本工具的核心数据边界见 `docs/privacy.md` 和公开 `/privacy` 页面。当前真实广告、激励广告、付费能力和图片识别公开模式都没有开放。隐私页已经补充广告 cookie、第三方广告技术和 AI 图片识别处理边界的基础披露；未来如果开放展示广告，也不应把日程标题、参与者姓名、上传图片、识别文本或可用时间作为广告定向字段主动传给广告平台。

## 公开页面

当前公开审核资产包括：

- `/`
- `/new`
- `/about`
- `/privacy`
- `/contact`
- `/feedback`
- `/terms`
- `/robots.txt`
- `/sitemap.xml`
- `/ads.txt`

动态日程页首期不进入 sitemap，带管理或编辑密钥的 URL 不应被公开索引。
